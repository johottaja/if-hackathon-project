## Käyttö prototyypin taustana

- Erota yleiset sopimusehdot, tuotekohtaiset ehdot, lisäturvat ja asiakkaan oma vakuutuskirja.
- Jos tuotat vastauksia dokumenttihaulla, säilytä dokumentin nimi, ehtoversio, kohta ja PDF-sivu vastauksen lähteenä.
- Julkiset ehdot eivät kerro asiakkaan valittua turvatasoa, omavastuuta tai henkilökohtaisia rajauksia.
- Vakuutuskirjan puuttuessa prototyyppi voi pyytää täsmennystä tai käyttää selvästi merkittyä esimerkkivakuutusta.
- Säilytä alkuperäiset PDF:t. `text/`-hakemistojen TXT:t ovat johdettuja poimintoja; taulukoiden ja sarakkeiden lukujärjestys voi vaatia tarkistamista.

Latausosoitteet ja tarkistussummat löytyvät [lähdeluettelosta](../SOURCES.md) ja
[sources.json](../sources.json)-tiedostosta.
